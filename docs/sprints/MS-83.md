# MS-83: Response Annotation — Thumbs Up/Down + Comment Feedback

## Goal
Add a lightweight feedback loop: users can rate any swarm response thumbs-up
or thumbs-down, optionally add a short comment, and the annotation is stored
server-side alongside the history entry. Annotations can later drive model
selection tuning or be exported with session data.

## Scope

### C++ — annotation endpoint

- **`cpp_core/src/coordinator_routes_annotations.h`** (new, inline) —
  Three routes:

  `POST /api/annotations` — body: `{ run_id, rating, comment? }` where
  `rating` is `1` (up) or `-1` (down). Stores into an in-memory
  `std::map<std::string, Annotation>` guarded by a mutex. Also writes
  `annotation` field back into the matching history entry.

  `GET /api/annotations/:run_id` — returns the annotation for one run.

  `GET /api/annotations` — returns all annotations as a JSON array,
  newest-first.

  Add `std::map<std::string, Annotation> annotations` and
  `std::mutex annotations_mutex` to `CoordinatorState`.

- **`cpp_core/src/coordinator_context.h`** — add the above fields.

### JS — annotation UI

- **`src/api/annotationsApi.js`** (new) —
  `submitAnnotation(runId, rating, comment)`, `fetchAnnotation(runId)`,
  `fetchAllAnnotations()`.

- **`src/components/ResponseRating.js`** (new) — thumbs-up 👍 + thumbs-down 👎
  buttons (text-based, no emoji dependency: `▲` / `▼` or `+1` / `−1`).
  Optional one-line comment input expands when a rating is selected.
  Calls `onRate(rating, comment)` prop. Shows current rating visually
  (filled vs outline).

- **`src/hooks/useResponseRating.js`** (new) — manages rating state for a
  single `runId`; calls `submitAnnotation` on submit; returns
  `{ rating, comment, setComment, submit, loading, error }`.

- **`src/components/ConversationTurn.js`** — add `ResponseRating` below the
  Fork button when `entry._run_id` is present.

## Files NOT touched
- History write path — annotation is a post-hoc overlay, not embedded at
  write time (avoids re-serialising the full history file on every annotation)
- `token_ledger`, `agent_health` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. `POST /api/annotations` with `{ run_id: "x", rating: 1 }` returns
   `{ saved: true }` and persists the annotation.
2. `GET /api/annotations/x` returns `{ run_id, rating, comment, timestamp }`.
3. `ResponseRating` shows filled `▲` when rating = 1, filled `▼` when −1.
4. Comment input appears on rating selection; submits with the rating.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
