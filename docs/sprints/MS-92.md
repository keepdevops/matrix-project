# MS-92 — Distillation App Integration Hooks

**Linear title:** Direct push to distillation app + webhook + schema docs
**Points:** 10
**Backlog item:** "Integration hooks for keepdevops/distillation app"

## Goal
Complete the data pipeline from the matrix swarm to the distillation training
app. Three deliverables:
1. **Direct push** — `POST /api/export/push` sends the trajectory bundle
   directly to a configured distillation app endpoint (local HTTP in
   air-gapped environments).
2. **Quality webhook** — when a session's average quality score crosses a
   configurable threshold, the coordinator fires a POST notification to the
   distillation app.
3. **Schema documentation** — `docs/distillation-schema.md` documents every
   field in the JSONL export so the distillation app can parse it without
   coupling to the coordinator source.

## Scope

### C++ — push endpoint

- **`cpp_core/src/coordinator_routes_push.h`** (new, inline) —
  `POST /api/export/push` body: `{ session_id?, min_quality?, target_url }`.
  - Calls `rl_traj::export_jsonl_filtered(session_id, min_quality)`.
  - POSTs the JSONL to `target_url` with
    `Content-Type: application/x-ndjson`.
  - Returns `{ pushed: true, lines: N, target_url, status_code }` on success.
  - Falls back gracefully: if `target_url` is unreachable, returns
    `{ pushed: false, error: "..." }` — never crashes the coordinator.

- **`cpp_core/src/coordinator_context.h`** — add:
  ```cpp
  std::string distillation_push_url; // coordinator.distillation.push_url
  double      distillation_quality_threshold = 0.6;
  ```

- **`cpp_core/src/coordinator_setup.cpp`** — read
  `coordinator.distillation.push_url` and
  `coordinator.distillation.quality_threshold`.

### C++ — quality webhook

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — after recording the
  RL trajectory, check if `st.distillation_push_url` is set and if the new
  trajectory's `quality_score >= st.distillation_quality_threshold`.
  If so, fire an async (detached thread) POST to
  `st.distillation_push_url + "/api/webhook/trajectory"` with the single
  trajectory JSON. Non-blocking — coordinator response is not delayed.

### Docs — distillation schema

- **`docs/distillation-schema.md`** — documents the JSONL export format:
  ```markdown
  # Matrix Swarm Distillation Export Schema
  ## Format: JSONL (one JSON object per line)
  ## Fields: session_id, run_id, mode, prompt, timestamp_ms,
  ##          tokens_consumed, budget, tes, gate_triggered,
  ##          fidelity_ratio, kv_auto_cleared, kv_pressure_before/after,
  ##          rag_hit_rate, rag_hits[], contracts[], any_overrun,
  ##          annotation_rating, annotation_comment, quality_score,
  ##          importance_scores{}, agent_outputs{},
  ##          supervisor_decisions (if enabled)
  ```

### JS — push UI

- **`src/api/distillationApi.js`** (new) — `pushTrajectories({ sessionId,
  minQuality, targetUrl })` → `POST /api/export/push`.

- **`src/components/ExportFilterPanel.js`** — add a "Push to distillation
  app" section: target URL input + "Push" button (separate from ↓ Export).
  Calls `pushTrajectories()`. Shows result inline (pushed N lines / error).

## Files NOT touched
