# MS-73: Token Budget Dashboard + Session Lifecycle Management

## Goal
Complete the token management sprint sequence (MS-68–MS-73) by adding a
dedicated budget dashboard panel, per-session lifecycle controls (pause on
overrun, auto-reset on new session), and a coordinator-level hard-stop that
refuses dispatch when a session is in overrun state.

## Scope

### C++ — overrun hard-stop

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — after computing the
  ledger state, if `ledger.overrun()` is true AND a new config flag
  `coordinator.reject_on_overrun` is set, return HTTP 429 with:
  ```json
  {"error": "token_budget_exceeded", "session_id": "...", "consumed": N, "budget": N}
  ```
  This lets the UI surface a clear "budget exhausted" state rather than
  silently truncating.

- **`cpp_core/src/coordinator_routes_architect_stream.cpp`** — same overrun
  check before starting the stream; emit an SSE `error` event with
  `{"type":"token_budget_exceeded"}` and close the stream.

- **`cpp_core/src/coordinator_context.h`** — add
  `bool reject_on_overrun = false;` to `CoordinatorState`.

- **`cpp_core/src/coordinator_setup.cpp`** — read
  `coordinator.reject_on_overrun` (bool, default false).

### JS — budget dashboard panel

- **`src/components/TokenBudgetDashboard.js`** (new) — standalone panel
  showing all active sessions' budget state. Reads from a new hook.
  Columns: session ID (truncated), budget, consumed, remaining, overrun badge,
  ↺ reset button per row.

- **`src/hooks/useAllSessionBudgets.js`** (new) — polls
  `GET /api/metrics-json` (see below) every 3s; returns array of session
  snapshots. Falls back gracefully when endpoint unavailable.

- **`cpp_core/src/coordinator_routes_metrics.h`** — add
  `GET /api/metrics-json` returning `token_ledger::all_sessions_snapshot()`
  as JSON array (already available; just needs a route).

### JS — session lifecycle

- **`src/hooks/useTokenBudget.js`** — add `pauseOnOverrun` option: when
  `overrun` flips to true, emit an `onOverrun` callback so callers can
  disable the submit button.

- **`src/components/PromptInput.js`** (or equivalent submit area) — accept
  `budgetExhausted` prop; when true, render the submit button disabled with
  tooltip "Token budget exhausted — reset to continue".

- **`src/hooks/useSubmitHandlers.js`** — wire `useTokenBudget`'s `overrun`
  state into `budgetExhausted`; pass down to `PromptInput`.

## Files NOT touched
- `token_ledger.h/.cpp` — no API changes needed (all_sessions_snapshot already exists)
- `agent_client_http.cpp` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. With `reject_on_overrun: true` in coordinator config, a dispatch after
   budget exhaustion returns HTTP 429 with `error: "token_budget_exceeded"`.
2. `GET /api/metrics-json` returns a JSON array of session snapshots.
3. `TokenBudgetDashboard` renders the session table without error.
4. Submit button is disabled when `overrun: true` from `useTokenBudget`.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
