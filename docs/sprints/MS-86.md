# MS-86 — Advanced Context Management: KVzip-Inspired Importance Eviction + Compaction

**Linear title:** Summarization gate, importance-aware KV eviction, compaction + RAG trajectory depth
**Points:** 16
**Maps to:** Original MS-70 research plan

## Goal
1. Upgrade the summarization gate (MS-69/MS-84) with quality feedback:
   when a summary is produced, record its symbolic importance score vs.
   the original so users and the distillation pipeline can learn whether
   summarization preserved meaning.
2. Introduce `kv_importance_indexer` — a training-free proxy for KV cache
   slot importance using norm, entropy, and recency heuristics. Used to guide
   which slots to clear first on `auto_clear_kv`.
3. Progressive compaction pipeline: multi-tier history compaction that drops
   low-importance history runs first.
4. Deepen RAG trajectory entries with evicted/retained KV importance scores
   and before/after pressure readings.
5. Upgrade smart KV clear to use importance-ordered eviction instead of full
   clear.

## Scope

### C++ — `kv_importance_indexer.h`

- **`cpp_core/src/kv_importance_indexer.h`** (new, inline) —
  ```cpp
  namespace kv_importance {
  struct SlotScore {
      int    port;
      double importance; // 0–1; higher = keep
      bool   should_evict(double threshold = 0.3) const;
  };
  // Score a port's KV slots using norm+entropy proxy on its recent output.
  // Falls back to recency (older = lower importance) when text unavailable.
  SlotScore score_port(int port, const std::string& recent_output,
                       int age_turns, double kv_fill_ratio);
  // Rank all active ports by importance ascending (evict lowest first).
  std::vector<SlotScore> rank_ports(
      const std::vector<Agent>& agents,
      const std::map<int, std::string>& port_recent_outputs,
      const std::map<int, int>& port_age_turns,
      const std::map<int, double>& port_kv_fills);
  }
  ```

- **`cpp_core/src/kv_auto_clear.h`** — upgrade `clear_kv()` to accept an
  optional `importance_threshold`: only clear ports whose importance score
  ≤ threshold, rather than clearing all ports. Logs which ports were skipped
  (high importance) and which were cleared.

### C++ — Progressive compaction

- **`cpp_core/src/session_compaction.h`** (new, inline) —
  ```cpp
  namespace session_compaction {
  // Score a session run by symbolic importance of its final/agent outputs.
  double score_run(const nlohmann::json& run);
  // Return run_ids to drop from session history to meet target_chars budget.
  // Drops lowest-scoring runs first (importance-ordered).
  std::vector<std::string> runs_to_drop(
      const nlohmann::json& session_runs,
      size_t target_chars);
  }
  ```
  Called from `session_build_continuation()` when context is too long
  instead of the current truncate-from-tail approach.
