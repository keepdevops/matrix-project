# MS-85 — Adaptive Controls + Symbolic Importance + RAG Enrichment

**Linear title:** Adaptive max_select, per-agent caps, symbolic importance foundation, enhanced RAG logging
**Points:** 14
**Maps to:** Original MS-69 research plan

## Goal
1. Full `effective_max_select()` using contract state, KV pressure, and a
   symbolic importance score derived from norm/entropy heuristics on agent
   responses.
2. `max_input_tokens` enforcement with truncation metadata surfaced in
   `meta.truncation`.
3. Hierarchical context tiers — active task vs. session history — so the
   most relevant context is prioritised.
4. Extend the RAG trajectory logger to capture per-agent context similarity
   (how relevant the retrieved context was to each agent's final output).

## Scope

### C++ — symbolic importance scorer

- **`cpp_core/src/symbolic_importance.h`** (new, inline) —
  ```cpp
  namespace symbolic_importance {
  // Norm score: normalised length of agent output relative to peers.
  double norm_score(const std::string& text, double peer_avg_len);
  // Entropy proxy: unique word count / total word count (lexical diversity).
  double entropy_score(const std::string& text);
  // Combined importance score 0–1.
  double score(const std::string& text, double peer_avg_len);
  // Rank a map of agent→text by importance score. Returns sorted pairs.
  std::vector<std::pair<std::string,double>>
      rank(const std::map<std::string,std::string>& outputs);
  }
  ```

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — after mode run,
  compute importance scores for each agent output and include them in
  `meta.importance` as `{ agent_name: score }`.

### C++ — effective_max_select with contracts + importance

- **`cpp_core/src/adaptive_select.h`** (new, inline) —
  ```cpp
  namespace adaptive_select {
  struct Factors {
      int   base_max_select;
      double kv_pressure;    // 0–1
      bool   any_overrun;    // from ContractLedger
      double avg_importance; // from last run's symbolic scores (0–1)
  };
  // Returns adjusted max_select:
  // - overrun or kv > 0.85 → max(1, base-2)
  // - kv > 0.70 → max(1, base-1)
  // - avg_importance > 0.7 → may increase by 1 (reward high quality)
  int compute(const Factors& f);
  }
  ```
  Replace the inline logic in `coordinator_routes_dispatch.cpp` with
  `adaptive_select::compute()`.

### C++ — truncation metadata

- **`cpp_core/src/agent_client_http.cpp`** — when `max_input_tokens` truncation

  After response, if truncation occurred, add `{ truncated: true, original_chars, truncated_chars }`

- **`cpp_core/src/coordinator_routes_dispatch_meta.h`** — add

### C++ — context tiers in session continuation

- **`cpp_core/src/session_store_context.h`** — add `tier_weights` to
  `session_build_continuation`: active-task context (last 2 runs) gets weight 1.0;
  older history gets weight 0.5. Compaction uses tier-weighted importance to
  decide what to drop first.
