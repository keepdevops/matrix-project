# MS-70: Metrics Feedback Loop — TES, Session Totals, Prometheus

## Goal
Close the observability gap by surfacing token-efficiency metrics in the UI,
persisting session totals across history entries, and exporting ledger state
to Prometheus so downstream monitoring can act on budget/pressure data.

## Scope

### C++ — Token-Efficiency Score (TES)
- **`cpp_core/src/tes.h`** (new, inline) — compute TES from ledger + timing:
  ```
  TES = (consumed_tokens / elapsed_ms) * quality_score
  ```
  Where `quality_score` is the existing `quality_pass` value (0.0–1.0, 1.0 if no QP).
  Expose `tes::compute(entry)` returning `double`.

- **`cpp_core/src/coordinator_routes_dispatch_meta.h`** — add `meta.tes` to envelope
  from `tes::compute()` after mode run completes.

- **`cpp_core/src/token_ledger.h`** — add `session_total()` → cumulative consumed
  across all sessions (used by Prometheus exporter).

- **`cpp_core/src/coordinator_routes_metrics.h`** (new, inline route) —
  `GET /api/metrics` returns Prometheus text format:
  ```
  matrix_token_consumed_total{session="..."} 1234
  matrix_token_budget_remaining{session="..."} 766
  matrix_kv_pressure{session="..."} 0.72
  matrix_tes{session="..."} 4.21
  ```

### JS — MetricsStrip session totals
- **`src/components/MetricsStrip.js`** — add session-cumulative token row:
  `TOTAL: consumed/budget (overrun badge if overrun)`.
  Read from `useTokenBudget` (already exists from MS-68).

- **`src/components/TesGauge.js`** (new) — small spark-line or bar showing TES
  trend over last 5 responses. Reads `meta.tes` from response envelope.

- **`src/hooks/useTesHistory.js`** (new) — accumulates last N TES values from
  dispatch responses; returns `{ history: number[], avg: number }`.

### JS — history entry enrichment
- **`src/utils/historyUtils.js`** (modify or new helper) — attach `token_budget`
  and `tes` fields from `meta` to each saved history entry for display in
  `ConversationThread`.

- **`src/components/ConversationTurn.js`** — render TES badge next to timing badge
  when `entry.meta.tes` is present.

## Files NOT touched
- `synthesis_budget.cpp` — no change in MS-70
- `coordinator_routes_dispatch.cpp` — meta stamping delegated to dispatch_meta helper
- Python test suite — no new scan anchors needed (no code moves)

## Acceptance Criteria
1. `GET /api/metrics` returns valid Prometheus text with at least the four metrics.
2. MetricsStrip shows session token totals alongside existing KV/CTX badges.
3. TesGauge renders in ConversationTurn without breaking existing tests.
4. `./scripts/build_cpp_binaries.sh` — clean build.
5. 924 JS + 28 Python tests pass.
