# MS-84 — Core Foundation: Agent Contracts + Hierarchical Budget + RAG Trajectory Hooks

**Linear title:** Hierarchical token_budget + Agent Contract primitives + initial RAG trajectory hooks
**Points:** 13
**Maps to:** Original MS-68 research plan

## Goal
Lay the research foundation for the token-regulation system:
1. Hierarchical token budget (global → mode → agent → task) with validation
2. `agent_contract` primitives — conservation laws, delegation caps, audit trail
3. Initial RAG trajectory hooks in the router path for distillation data collection

## Scope

### C++ — Hierarchical budget

- **`cpp_core/src/token_budget_hierarchy.h`** (new) — struct + loader:
  ```cpp
  struct BudgetHierarchy {
      int global = 0;          // 0 = unlimited
      std::map<std::string, int> mode;   // per-mode override
      std::map<std::string, int> agent;  // per-agent override
  };
  BudgetHierarchy load_hierarchy(const nlohmann::json& coordinator_block);
  int resolve(const BudgetHierarchy&, const std::string& mode,
              const std::string& agent); // returns most-specific non-zero budget
  ```

- **`cpp_core/src/coordinator_context.h`** — replace `int global_token_budget`
  with `BudgetHierarchy token_budget_hierarchy`.

- **`cpp_core/src/coordinator_setup.cpp`** — call `load_hierarchy()`.

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — use `resolve()` to
  compute the effective budget per dispatch (mode + agents present).

### C++ — Agent contracts

- **`cpp_core/src/agent_contract.h`** (new) — conservation laws + delegation:
  ```cpp
  struct AgentContract {
      std::string agent_name;
      int         token_allocation = 0;   // from hierarchy
      int         tokens_used      = 0;
      int         max_delegations  = 1;   // how many sub-calls allowed
      int         delegations_used = 0;
      bool        overrun()    const;
      bool        can_delegate() const;
  };
  struct ContractLedger {
      std::map<std::string, AgentContract> contracts;
      nlohmann::json audit_trail = nlohmann::json::array();
      void record(const std::string& agent, const std::string& event,
                  int tokens, const std::string& run_id);
  };
  ```
  Add `ContractLedger contract_ledger` + `std::mutex contract_mutex` to
  `CoordinatorState`.

- **`cpp_core/src/agent_client_http.cpp`** — after response: record tokens to
  `ContractLedger::record()` using `session_context::current()` + agent name.

- **`cpp_core/src/modes/mode.h`** — add `ContractLedger* contracts = nullptr`
  to `ModeContext` (nullable; dispatcher sets it).

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — build per-agent contracts
  before mode run; write contracts into `ModeContext`; add `meta.contracts`
  (overrun flags + delegation counts) to envelope after run.

### C++ — RAG trajectory hooks

- **`cpp_core/src/rag_trajectory.h`** (new, inline) —
  ```cpp
  namespace rag_trajectory {
  struct Entry {
      std::string session_id, run_id, query;
      std::vector<double> query_embedding;
      std::vector<nlohmann::json> hits; // {source, distance, relevance?}
      long long timestamp_ms;
  };
  // Thread-safe ring buffer (last 500 entries).
  void record(Entry e);
  nlohmann::json snapshot(); // for export endpoint
  void clear();
  }
  ```
  Called from `dispatch_build_rag()` after retrieval.

- **`cpp_core/src/coordinator_routes_dispatch_prepare.cpp`** — after `rag::retrieve()`,
  call `rag_trajectory::record()` with query, embeddings, and hits.

- **`cpp_core/src/coordinator_routes_rag_trajectory.h`** (new) —
  `GET /api/rag-trajectories?session_id=` — returns snapshot filtered by session.
  Stub export endpoint: `GET /api/export/rl-trajectories?session_id=` returns
  `{ trajectories: [], contracts: [], note: "full export in MS-87" }`.
