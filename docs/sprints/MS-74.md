# MS-74: Agent Health Observability — Circuit Breaker Dashboard + Prometheus

## Goal
The circuit breaker (MS-68 area, `agent_health.cpp`) already trips and
recovers, but the state is invisible to operators and users. This sprint
surfaces breaker state in Prometheus, adds a dedicated health dashboard
component, and shows an inline warning in the UI when agents are excluded
from a dispatch due to open breakers.

## Background
`agent_health::is_open(name)` is queried at dispatch time; excluded agents
are logged to coordinator stdout and included in `meta.excluded_unhealthy`.
The snapshot endpoint `GET /api/agents/health` (via `agent_health_snapshot.h`)
returns JSON. Prometheus and the JS side currently have no visibility into
this data.

## Scope

### C++ — Prometheus breaker metrics

- **`cpp_core/src/coordinator_routes_metrics.h`** — extend `GET /api/metrics`
  with per-agent circuit breaker metrics:
  ```
  # HELP matrix_agent_breaker_open Circuit breaker open (1) or closed (0)
  matrix_agent_breaker_open{agent="coder"} 0
  # HELP matrix_agent_breaker_failures Recent failure count in sliding window
  matrix_agent_breaker_failures{agent="coder"} 1
  # HELP matrix_agent_breaker_cooldown_ms Cooldown remaining in ms (0 when closed)
  matrix_agent_breaker_cooldown_ms{agent="coder"} 0
  ```
  Read from `agent_health::snapshot()` (already returns this data as JSON).

### JS — health dashboard

- **`src/hooks/useAgentHealth.js`** (new) — polls `GET /api/agents/health`
  every 5s; returns `{ byName: { [agent]: { recent_failures, tripped,
  cooldown_remaining_ms } } }`.

- **`src/components/AgentHealthBadge.js`** (new) — small inline badge:
  green dot (healthy), amber dot (recent failures > 0), red dot (tripped).
  Accepts `{ name, health }` props.

- **`src/components/AgentHealthDashboard.js`** (new) — table of all agents
  with name, status badge, failure count, cooldown bar (progress bar showing
  `cooldown_remaining_ms / COOLDOWN_MS`). Auto-refreshes via `useAgentHealth`.

- **`src/components/MetricsStrip.js`** — when `meta.excluded_unhealthy` is
  non-empty, render a red `EXCL N` badge in the strip header listing the
  excluded agent names on hover.

### JS — dispatch warning

- **`src/hooks/useSubmitHandlers.js`** — before submitting, check
  `useAgentHealth`'s `byName` for any tripped agents that are in
  `activeAgents`; call `onModeWarning` with a list of
  `"${name} circuit breaker open"` strings (same pattern as `modeWarnings`).

## Files NOT touched
- `agent_health.cpp` / `agent_health.h` — breaker logic unchanged
- `token_ledger` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. `GET /api/metrics` includes `matrix_agent_breaker_open` lines for each agent.
2. `AgentHealthDashboard` renders without error; polling stops when offline.
3. `MetricsStrip` shows `EXCL N` badge when `meta.excluded_unhealthy` is set.
4. A tripped agent in `activeAgents` triggers a mode warning before submit.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
