# MS-26 — `tree_of_thought` + Streaming Orchestrate + RAG UX Polish

**Sprint:** June 28 – July 11, 2026  
**Status:** In progress  
**Goal:** Enable the final Python mode (`tree_of_thought`), replace the blocking orchestrate response with SSE streaming, and complete RAG integration across all Python modes.

## Context

MS-25 shipped the proxy passthrough and enabled `map_reduce`, `speculative`, `critic_debate` with memory caps and RAG-aware chunking. Three loose ends remain:

- `tree_of_thought` was deferred in MS-25 pending memory cap stability — caps are proven, ready to enable
- `/api/orchestrate` returns blocking JSON; long `tree_of_thought` runs (depth 2, branching 3 = up to 9 agent calls) need live streaming
- `speculative` and `critic_debate` don't yet receive RAG context (only `map_reduce` does — MS-25-5)

## Item notes

### MS-26-1 — `tree_of_thought` UI

- Flip `tree_of_thought` to `enabled: true, ui: true` in `modeManifestData.js`
- Role controls in `PromptInput`: generator + scorer dropdowns; depth slider (1–3); branching slider (2–4); prune_below input
- Route through the generalised Python orchestrate intercept in `useSubmitHandlers` (same path as other modes)
- Memory cap: weight 3 → `modeOverheadGb = 3.0 GB` in `computeRiskEstimate`; blocks at 33 GB as designed

### MS-26-2 — SSE streaming for `/api/orchestrate`

- Add `POST /api/orchestrate/stream` on the proxy (`proxy_routes.cpp`) — forwards to Python coord `/api/orchestrate/stream`
- `service_orchestrate.py`: new `handle_orchestrate_stream` handler that streams `Event` objects as SSE (`event: token`, `event: agent_start`, `event: done`)
- `useSwarm.submit` orchestrate path: switch from `submitOrchestrate` (blocking) to `submitOrchestrateStream` (SSE), wiring into existing `onToken` / `onAgentDone` / `onDone` callbacks
- Fallback: if stream endpoint returns 404 (Python coord not updated), fall back to blocking JSON

### MS-26-3 — RAG context for `speculative` + `critic_debate`

- Extend `service_orchestrate.py` `_fetch_rag_chunks` call to cover `speculative` and `critic_debate` (currently only `map_reduce`)
- `speculative.py`: inject `rag_block` into drafter and verifier prompts
- `critic_debate.py`: inject `rag_block` into generator prompt; critic prompt receives retrieved context so it can validate factual accuracy

### MS-26-4 — RAG citation panel

- When orchestrate result `meta.rag_chunks` is present, render a collapsible citation list below the Final Answer panel
- Reuse `RagSources.js` pattern — shows `source_path` + distance per chunk
- Wire `meta.rag_chunks` into `lastMeta` from orchestrate response (add to `submitOrchestrate` return and `setLastMeta` in `useSwarm`)
