## Goal
Give the coordinator a session-scoped token ledger, enforce per-agent
input caps, and surface budget + KV pressure in the Foreman (classifier)
prompt so it can adaptively shrink `max_select` before the system runs out
of headroom.

## 2. C++ — new files

### `cpp_core/src/token_ledger.h` + `token_ledger.cpp`

```cpp
namespace token_ledger {

struct Entry {
    int budget = 0;           // 0 = unlimited
    int consumed = 0;
    int remaining() const { return budget > 0 ? std::max(0, budget - consumed) : -1; }
    bool overrun()  const { return budget > 0 && consumed >= budget; }
};

// Session-keyed, mutex-guarded
void   set_budget(const std::string& session_id, int budget);
void   add(const std::string& session_id, int tokens);
Entry  get(const std::string& session_id);
void   reset(const std::string& session_id);
nlohmann::json snapshot(const std::string& session_id);

} // namespace token_ledger
```

Implementation: `std::map<std::string, Entry>` with `std::mutex`.
Lives as a process-global (same pattern as `agent_health.cpp`).

### `cpp_core/src/coordinator_routes_token_budget.h`

Inline route handler (included by `coordinator_routes.cpp` or equivalent):

```

→ { session_id, budget, consumed, remaining, overrun }
```

### `cpp_core/src/agent_client.cpp`

Two changes:

**a) Prompt truncation** — in `call_agent()` before building the HTTP body:

```cpp
std::string effective_prompt = prompt;
if (agent.max_input_tokens > 0 && (int)prompt.size() > agent.max_input_tokens * 4)
    effective_prompt = prompt.substr(0, agent.max_input_tokens * 4);
    // 4 chars ≈ 1 token (rough; good enough for hard cap)
```

**b) Token counting** — parse `usage` from the llama-server JSON response
and call `agent_metrics::record()` with real token counts (currently called
with `words` and `prompt_tokens = -1`):

```cpp
long prompt_toks = -1, completion_toks = words;
if (res && res->body.size() > 2) {
    try {
        auto j = json::parse(res->body);
        if (j.contains("usage")) {
            prompt_toks     = j["usage"].value("prompt_tokens",     -1);
            completion_toks = j["usage"].value("completion_tokens", words);
        }
    } catch (...) {}
}
agent_metrics::record(agent.name, ms, completion_toks, prompt_toks);
token_ledger::add(session_context::current(), prompt_toks + completion_toks);
```

`session_context::current()` — a thread-local string set at dispatch entry
and cleared on exit (see coordinator_routes_dispatch.cpp below).

### `cpp_core/src/coordinator_routes_dispatch.cpp`

Three changes:

**a) Set session context** at top of handler (thread-local so `call_agent`
can read it without passing it everywhere):

```cpp
session_context::set(dreq.session_id);
// ... existing dispatch ...
session_context::clear();
```

**b) Load effective budget** from mode config + global fallback:

```cpp
int effective_budget = st.global_token_budget;
if (cfg_for_mode.contains("token_budget"))
    effective_budget = cfg_for_mode["token_budget"].get<int>();
if (effective_budget > 0)
    token_ledger::set_budget(dreq.session_id, effective_budget);
```

**c) Adaptive max_select** — read KV pressure from request body
(`kv_pressure` float 0–1, optional) and budget state to shrink
`effective_max_select`:

```cpp
double kv_pressure = dreq.kv_pressure;   // new field on DispatchRequest
auto ledger = token_ledger::get(dreq.session_id);
int base_max_select = cfg_for_mode.value("max_select", 5);
int effective_max_select = base_max_select;
if (kv_pressure > 0.70 || ledger.overrun())
    effective_max_select = std::max(1, base_max_select - 1);
if (kv_pressure > 0.85)
    effective_max_select = std::max(1, base_max_select - 2);
cfg_for_mode["max_select"] = effective_max_select;
cfg_for_mode["_budget_remaining"] = ledger.remaining();
cfg_for_mode["_kv_pressure"] = kv_pressure;
```

### `cpp_core/src/modes/router_classifier.cpp` (or stream equivalent)

Inject budget context into the Foreman user message (not system prompt —
avoid polluting KV cache):

```cpp
std::string budget_hint;
if (ctx.budget_remaining >= 0)
    budget_hint += "\n[Budget: " + std::to_string(ctx.budget_remaining)
                + " tokens remaining]";
if (ctx.kv_pressure > 0.5)

                + "% — prefer fewer agents]";

```
