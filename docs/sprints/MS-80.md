# MS-80: Response Diff — A/B Comparison of History Entries

## Goal
Allow users to select two history entries and view a word-level diff of their
responses side-by-side. This helps evaluate prompt variations, model changes,
or the effect of re-ranking and quality passes.

## Scope

### C++ — diff endpoint

- **`cpp_core/src/coordinator_routes_history_diff.h`** (new, inline) —
  `POST /api/history/diff` body: `{ run_id_a, run_id_b }`.
  Returns the two entries' prompts, final answers, and per-agent responses
  for the client to diff locally. No server-side diff computation — the
  coordinator just fetches both entries and returns them together:
  ```json
  { "a": { "run_id", "prompt", "final", "agents": {} },
    "b": { "run_id", "prompt", "final", "agents": {} } }
  ```

### JS — diff UI

- **`src/api/historyApi.js`** — add `diffHistory(runIdA, runIdB)` →
  `POST /api/history/diff`.

- **`src/utils/wordDiff.js`** (new) — `wordDiff(a, b)` returns an array of
  `{ text, type }` tokens where `type` is `'same' | 'add' | 'remove'`.
  Uses a simple LCS-based word-level diff (no external library).

- **`src/components/DiffView.js`** (new) — renders two text columns with
  word-level highlighting: removed words in red strikethrough, added words in
  green. Accepts `{ textA, textB, labelA, labelB }` props.

- **`src/components/HistoryDiffPanel.js`** (new) — two-entry selector:
  each slot shows a recent history search (`HistorySearch`) to pick an entry.
  Once both are selected, calls `diffHistory` and renders `DiffView` for
  the final answer and optionally per-agent responses.

- **`src/hooks/useHistoryDiff.js`** (new) — manages selection state for
  entry A and B; calls `diffHistory` when both are set; returns
  `{ entryA, setEntryA, entryB, setEntryB, diff, loading, error, clear }`.

## Files NOT touched
- `coordinator_routes_history_search.h` — search unchanged
- `token_ledger` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. `POST /api/history/diff` returns both entries' data or 404 for unknown run_id.
2. `wordDiff` produces correct `same/add/remove` tokens for simple inputs.
3. `DiffView` renders green/red highlighted words without error.
4. `HistoryDiffPanel` lets the user pick two entries and shows the diff.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
