# MS-87 — Metrics, TES & Full RL Trajectory Collector

**Linear title:** Enhanced TES, rich observability + complete RAG-powered RL trajectory system
**Points:** 14
**Maps to:** Original MS-71 research plan

## Goal
1. Upgrade TES to use density (tokens/char), fidelity (from gate), and
   RAG-grounded contribution heuristics for a richer quality signal.
2. Build the full `rl_trajectory_logger` module — hooks across dispatch,
   supervisor, and KV ops — that collects complete per-run records for the
   distillation pipeline.
3. Prometheus counters for importance distributions and RAG hit rates.
4. Complete `GET /api/export/rl-trajectories` with structured JSONL bundle
   consumable by the `keepdevops/distillation` app.
5. "Impact Dashboard" JS panel showing trajectory stats + Export Dataset button.

## Scope

### C++ — enhanced TES

- **`cpp_core/src/tes.h`** — upgrade `compute()`:
  ```cpp
  struct TesFactors {
      double consumed_tokens;
      double wall_ms;
      double fidelity_ratio;    // from context_gate; 1.0 when no gate
      double avg_importance;    // from symbolic_importance
      double rag_hit_rate;      // hits / top_k; 0 when no RAG
  };
  // TES = (density * 0.4 + fidelity * 0.3 + importance * 0.2 + rag_contrib * 0.1)
  //   where density = min(1, consumed / (wall_ms * 0.5))
  double compute_rich(const TesFactors& f);
  // Backward-compat: wraps the old envelope-based path, enriches when possible.
  double compute(const nlohmann::json& meta);
  ```

### C++ — rl_trajectory_logger module

- **`cpp_core/src/rl_trajectory_logger.h`** (new) — central struct collecting
  one complete record per dispatch run:
  ```cpp
  struct RlTrajectory {
      std::string   session_id, run_id, mode;
      std::string   prompt;
      long long     timestamp_ms;
      // Agent outputs + importance scores
      std::map<std::string, std::string>  agent_outputs;
      std::map<std::string, double>       importance_scores;
      // Token accounting
      int   tokens_consumed, budget;
      double tes;
      // Context
      bool   gate_triggered; double fidelity_ratio;
      bool   kv_auto_cleared;
      double kv_pressure_before, kv_pressure_after;
      // RAG
      nlohmann::json rag_hits;   // from rag_trajectory
      double         rag_hit_rate;
      // Contract state
      nlohmann::json contracts;  // from ContractLedger snapshot
      bool           any_overrun;
      // User feedback
      int    annotation_rating;  // 1/-1/0=none
      std::string annotation_comment;
  };
  // Async ring buffer (last 2000 entries).
  void record(RlTrajectory t);
  nlohmann::json snapshot(const std::string& session_id = "");
  // Export as JSONL string for distillation app.
  std::string export_jsonl(const std::string& session_id = "");
  void clear();
  ```

- **`cpp_core/src/coordinator_routes_dispatch.cpp`** — after all meta is stamped,
  assemble and record a `RlTrajectory` from the envelope + ContractLedger +
  rag_trajectory buffer.

### C++ — enhanced Prometheus metrics

- **`cpp_core/src/coordinator_routes_metrics.h`** — add:
  ```
  matrix_importance_avg          (gauge) — rolling avg_importance across recent runs
  matrix_rag_hit_rate            (gauge) — hits/top_k across recent trajectory entries
  matrix_tes_avg                 (gauge) — rolling TES average
  matrix_trajectory_count        (counter) — total RL trajectories recorded
  ```
  All derived from `rl_trajectory_logger::snapshot()`.

### C++ — full export endpoint

- **`cpp_core/src/coordinator_routes_rag_trajectory.h`** — replace the stub
  `GET /api/export/rl-trajectories` with the full implementation:
  - Returns `Content-Type: application/x-ndjson`
  - `Content-Disposition: attachment; filename="trajectories-<session_id>.jsonl"`
  - Body: JSONL from `rl_trajectory_logger::export_jsonl(session_id)`
  - Each line: one `RlTrajectory` as JSON (documented schema for distillation app)

### JS — Impact Dashboard

- **`src/components/ImpactDashboard.js`** (new) — panel showing:
  - Session TES trend (last 10 runs) using `TesGauge`
  - Avg importance bar
  - RAG hit rate
  - Total trajectories recorded
  - "Export Dataset" button → triggers `GET /api/export/rl-trajectories?session_id=`
    download (calls browser anchor-click pattern)

- **`src/api/trajectoryApi.js`** (new) — `exportTrajectories(sessionId)` triggers
  the JSONL download.

- **`src/hooks/useImpactStats.js`** (new) — polls `GET /api/metrics-json` every
  5s for trajectory counts + TES/importance averages; derives stats for the dashboard.
