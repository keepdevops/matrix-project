# MS-82: Prompt Templates — Saved Reusable Prompts with Variable Substitution

## Goal
Power users repeatedly type similar prompts with minor variations (language,
file path, topic). This sprint adds a server-side prompt template store and
a lightweight `{{variable}}` substitution engine, so users can save, manage,
and fill templates from the UI.

## Scope

### C++ — template store

- **`cpp_core/src/coordinator_routes_templates.h`** (new, inline) — four routes:
  - `GET /api/templates` — return `{ name: { text, description?, variables? } }`
  - `PUT /api/templates/:name` — save/update a template (`{ text, description }`)
  - `DELETE /api/templates/:name` — remove a template
  - `POST /api/templates/:name/render` — body: `{ variables: { key: value } }`;
    returns `{ rendered }` with `{{key}}` placeholders substituted.

  Templates are stored in `CoordinatorState` alongside presets (same JSON
  persistence pattern via `coordinator_persist_modes_locked`).
  Add `nlohmann::json templates = json::object()` and
  `std::mutex templates_mutex` to `CoordinatorState`.

- **`cpp_core/src/coordinator_context.h`** — add `templates` + `templates_mutex`.

- **`cpp_core/src/coordinator_setup_wire.h`** — load `coordinator.templates`
  from config on startup (optional block).

### JS — template manager UI

- **`src/api/templatesApi.js`** (new) —
  `fetchTemplates()`, `saveTemplate(name, data)`,
  `deleteTemplate(name)`, `renderTemplate(name, variables)`.

- **`src/utils/templateSubstitute.js`** (new) —
  `substitute(text, variables)` — replaces `{{key}}` with `variables[key]`;
  returns the rendered string. Also `extractVariables(text)` — returns
  `string[]` of unique variable names found in `{{...}}` patterns.

- **`src/hooks/useTemplates.js`** (new) — CRUD state for templates;
  returns `{ templates, save, remove, render, loading, error }`.

- **`src/components/TemplateManager.js`** (new) — list of saved templates
  with edit (pencil), delete, and "Use" button. Clicking "Use" expands
  an inline variable fill form (one input per extracted variable) and
  emits `onInsert(renderedText)` so the parent can set the prompt textarea.

- **`src/components/TemplatePicker.js`** (new) — compact dropdown that lists
  template names; selecting one emits `onSelect(name)`. Used inline in
  `PromptInput` area so users can load a template without opening the full
  manager.

## Files NOT touched
- `coordinator_routes_presets.cpp` — presets logic unchanged
- `token_ledger`, `agent_health` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. `PUT /api/templates/review-code` saves `{ text: "Review this {{language}} code: {{code}}" }`.
2. `POST /api/templates/review-code/render` with `{ variables: { language: "Python", code: "..." } }` returns rendered text.
3. `extractVariables("Fix {{lang}} bug in {{file}}")` returns `["lang", "file"]`.
4. `TemplateManager` shows variables form when "Use" is clicked.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
