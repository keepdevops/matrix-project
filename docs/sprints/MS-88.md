# MS-88 — Swarm Supervisor with Contract-Driven Policy Engine

**Linear title:** Swarm Supervisor + symbolic policy engine using contracts & RAG data
**Points:** 15
**Maps to:** Original MS-72 research plan

## Goal
Introduce a `swarm_supervisor` module that runs between dispatch rounds to:
1. Analyse contract state, importance scores, and RAG trajectory data.
2. Emit policy decisions: prune agents, suggest model hints, deprioritize
   low-importance participants.
3. Write an audit log of all policy decisions linked to trajectory records.
4. Optionally gate mid-run intervention (disable by default).
5. Include supervisor reasoning in RL trajectory exports.

## Scope

### C++ — `swarm_supervisor.h`

- **`cpp_core/src/swarm_supervisor.h`** (new, inline) —
  ```cpp
  namespace swarm_supervisor {

  struct PolicyDecision {
      std::string agent_name;
      std::string action;   // "prune" | "deprioritize" | "hint" | "ok"
      std::string reason;
      double      confidence; // 0–1
  };

  struct SupervisorResult {
      std::vector<PolicyDecision> decisions;
      bool                        any_intervention;
      nlohmann::json              audit_entry;
  };

  // Analyse the last N trajectories + current contract ledger + KV pressure.
  // Returns policy decisions for this session's active agents.
  SupervisorResult analyse(
      const std::vector<Agent>&         agents,
      const ContractLedger&             ledger,
      double                            kv_pressure,
      const nlohmann::json&             recent_trajectories, // from rl_traj::snapshot
      bool                              enabled = true);

  // Apply decisions: remove "prune" agents from the vector.
  // "deprioritize" agents move to end of vector.
  // Returns modified agent list.
  std::vector<Agent> apply(const std::vector<Agent>& agents,
                            const SupervisorResult&   result);
  }
  ```

  **Policy rules (rule-based, no model required):**
  - Prune agent if: overrun in contract AND importance_score < 0.3
  - Deprioritize agent if: importance_score < 0.4 AND kv_pressure > 0.7
  - Hint (log only) if: rag_hit_rate low AND agent tagged "rag"
  - ok: otherwise
