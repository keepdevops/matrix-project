# MS-30 — BrewlateLayout Split + agent_client Refactor

**Sprint:** August 23 – September 5, 2026  
**Status:** Done  
**Goal:** Eliminate the two largest LOC violations — `BrewlateLayout.js` (871 LOC, 3× the limit) and `agent_client.cpp` (298 LOC, approaching limit) — and land targeted follow-up from MS-29.

## Context

MS-29 cleared the C++ stream and proxy files. Two violations remain:

1. **`BrewlateLayout.js` is 871 LOC** — the dominant structural debt. It houses the entire Brewlatte UI: deploy state, configure panel, session tabs, agent grid, code results, RAG tab, mode selector, prompt input, monitor popout, and all event handlers. Splitting by feature panel is the right boundary.
2. **`agent_client.cpp` is 298 LOC** — 2 LOC under the limit, but growing with each sprint. Contains HTTP client calls, retry logic, and agent health probing that belong in separate files.
3. **`PromptInput.js` is 277 LOC** — the role-selector block added for Python modes (MS-25-3/MS-26-1) is the natural extraction target.
4. **`configApi.js` is 290 LOC** — orchestrate history functions and configure-status polling can be split into `orchestrateApi.js` (partially done) and `configureApi.js`.
