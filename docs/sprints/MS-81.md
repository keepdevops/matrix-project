# MS-81: Session Export — Download Conversation as Markdown / JSON

## Goal
Allow users to download a full conversation session (all turns belonging to
a given `session_id`) as a Markdown transcript or raw JSON. This is useful
for sharing, archiving, and offline review of swarm outputs.

## Scope

### C++ — session export endpoint

- **`cpp_core/src/coordinator_routes_session_export.h`** (new, inline) —
  Two routes:

  `GET /api/sessions/:session_id/export.md`
  Returns a Markdown transcript:
  ```markdown
  # Session: <session_id>
  Exported: <timestamp>

  ## Turn 1 — <ISO timestamp>
  **You:** <prompt>

  **Swarm:** <final answer or best agent response>
  ---
  ```

  `GET /api/sessions/:session_id/export.json`
  Returns the raw array of history entries for the session as a JSON file
  download (`Content-Disposition: attachment; filename="<session_id>.json"`).

  Both routes scan `st.history` for entries where `_session_id` matches,
  ordered by `timestamp`.

### JS — export buttons

- **`src/api/sessionApi.js`** (new) —
  `exportSessionMd(sessionId)` triggers a browser download of the `.md` URL.
  `exportSessionJson(sessionId)` triggers a browser download of the `.json` URL.

- **`src/components/SessionExportButtons.js`** (new) — two small buttons:
  `↓ MD` and `↓ JSON`. Accepts `sessionId` prop; disabled when no sessionId.
  Uses `<a download>` pattern via `sessionApi`.

## Files NOT touched
- `coordinator_routes_history_search.h` / fork / diff — unchanged
- `token_ledger`, `agent_health` — no changes
- Python test suite — no scan anchors needed

## Acceptance Criteria
1. `GET /api/sessions/:session_id/export.md` returns a valid Markdown document
   with one section per history turn.
2. `GET /api/sessions/:session_id/export.json` returns JSON with
   `Content-Disposition: attachment`.
3. `SessionExportButtons` renders two download buttons when `sessionId` is set.
4. Clicking `↓ MD` downloads a `.md` file; clicking `↓ JSON` downloads a `.json`.
5. `./scripts/build_cpp_binaries.sh` — clean build.
6. 924 JS + 28 Python tests pass.
